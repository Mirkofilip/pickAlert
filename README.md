# PickAlert

PWA Vue 3 + Supabase, installabile dalla schermata Home **senza notifiche push**.
La città viene scelta nelle impostazioni; il feed si aggiorna mentre l'app è
aperta e connessa. 

## Locale

```sh
npm install
npm run dev
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```
